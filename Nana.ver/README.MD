DMnote skin 기본 세팅 (StelLive Hanako Nana.ver)

# 앱 설정
- "항상 위에 표시" 켜기
- "노트 효과 표시" 켜기
- "키 카운터 표시" 켜기
- "커스텀 CSS 활성화" 켜기
- "JS 플러그인 활성화" 켜기

나머지 값은 원하는대로


# 기본 세팅 
- 우클릭후 "현재 탭 트랙 설정" 클릭
- 프레힘 제한 0 | 속도 240 | 틀랙 높이 150 | 페이트 인:50 아웃:20
- 불러 올때는 프로필 생성후 "현재 탭에 불러오기"로 불러오기
- "현재 탭 CSS 설정" CSS 적용후 저장

# 이미지 바꾸는법
- .CSS 파일에서 background 라는 값을 찾아 url 부분의 링크를 수정후 저장
