# DMnote skin StelLive
DMnote에 적용 가능한 스킨 파일입니다

본 스킨은 그냥 심심해서 만들어본 스킨입니다 

- - -


스킨별로 있는 CSS 파일에서 

- background: url("https://Image_Link_Here_BY_KEY") center/cover no-repeat !important;

부분코드의 링크 부분만 수정하고 저장하면 이미지가 뜹니다

> 총 4줄만 수정하시면 됩니다

- https://Image_Link_Here_BY_KEY

- https://Image_Link_Here_BY_LINE1

- https://Image_Link_Here_BY_LINE2

- https://Image_Link_Here_BY_GRAPBG
